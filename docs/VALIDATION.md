# 0.1.0 검증 기록

검증일: 2026-10-09. Windows 11 x64, Python 3.12.10, PySide6 6.10.2, 내장 FFmpeg 7.1.2.

## 통과

- 단위 테스트 5개: 필기 되돌리기/지우기, 한국어 SRT/CP949 SMI, 업데이트 서명 변조 거부, 버전/HTTPS 검사, 다운로드 크기/해시 불일치 거부.
- 실제 Qt 재생: MOV H.264 + AAC, MOV HEVC Main 10, MOV ProRes, MOV 회전 메타데이터, MP4 H.264, MKV H.264.
- 실제 마우스 이벤트로 재생 중 필기. 필기 중 재생 시간이 계속 증가함을 확인.
- 정지 중 필기/캡처. 정지 시점이 유지됨을 확인.
- 영상과 필기가 포함된 1920×1080 PNG의 필기 위치 픽셀 확인.
- Qt 합성 터치 이벤트를 Windows QWindow에 주입하여 필기 획 생성 확인.
- 창 → 수업 전체 화면 → 완전 전체 화면, Esc 복귀, 모드 전환 시 필기 유지.
- 패키징된 SsenPlayer.exe에서 H.264 / HEVC / ProRes / 회전 MOV 재생 및 필기 캡처.
- 최종 Inno Setup 설치 파일을 작업 폴더 내 독립 경로에 설치한 후 재생/캡처, 제거 확인.

## 관측값

- 설치 파일: 약 40.8MiB.
- 무설치 ZIP: 약 57.0MiB.
- 압축 해제된 실행 파일 묶음: 약 142MiB.
- 패키징된 앱의 main.py 시작 → 창 구성 계측: 테스트별 약 1.76–2.26초. 설치본에서는 1.85초. 부트로더/디스크 캐시/PC 환경에 따라 달라지며 콜드 스타트 성능 보장이 아님.
- 개발 실행에서 960×540 샘플 재생 후 정지 상태 RSS: 약 250MiB. 고해상도 영상/그래픽 드라이버/필기량에 따라 달라짐.

원본 검사 산출물은 로컬 `artifacts/qa`에 저장됩니다. 재생 샘플은 `scripts/make_test_media.ps1`로 재현할 수 있으며 사용자 영상은 사용하지 않았습니다.

## 미검증 / 후속

- 실제 전자칠판 모델별 펜·터치 지연, 손바닥 거부, 필압, DPI, 여러 화면.
- 실제 아이폰 Dolby Vision/HDR 영상의 색 정확도와 4K/8K 장시간 재생 성능.
- 온라인 업데이트 피드와 이전 버전에서 새 버전으로의 실제 업그레이드. 배포 주소는 아직 비어 있음.
- 모든 파일/코덱 호환성, DRM, ASS 고급 자막, 손상된 미디어.
