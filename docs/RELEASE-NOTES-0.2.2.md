# 쎈player 0.2.2 · 전자칠판 수업용 영상 플레이어

**영상을 보면서 바로 필기하고, 설명한 장면을 수업 자료로 저장하세요.**

쎈player는 Windows PC와 전자칠판에서 사용할 수업용 영상 플레이어입니다. 영상을 재생하거나 멈춘 상태에서 펜과 형광펜으로 표시하고, 필요한 장면을 필기와 함께 캡처하거나 녹화할 수 있습니다. 같은 장면을 여러 번 설명할 때는 구간 반복을 사용합니다.

로컬 영상 재생에는 광고가 없으며, AV1·H.264·HEVC 등의 재생 코덱을 포함합니다. 별도 코덱 팩이나 Python을 설치할 필요가 없습니다. YouTube 링크도 앱 안에서 열 수 있습니다.

<img src="https://raw.githubusercontent.com/HooniKims/ssen-player/8238bad320129c21851e5f282d089ac4aca75b2e/docs/images/intro-0.2.2/02-video-ink.png" alt="진자 예시 영상을 재생하고 빨간 펜으로 표시한 쎈player 전체 화면 구성" width="1000">

*실제 v0.2.2 앱 화면입니다. 진자 영상은 소개를 위해 직접 제작한 예시이며, 빨간 원과 화살표는 플레이어의 필기 기능으로 그렸습니다. 예시 영상은 설치 파일에 포함되지 않습니다.*

## 다운로드와 시작 방법

| 파일 | 사용 방법 |
| --- | --- |
| [설치 EXE 다운로드](https://github.com/HooniKims/ssen-player/releases/download/v0.2.2/SsenPlayer-Setup-0.2.2.exe) | Windows x64에서 설치 파일을 실행합니다. |
| [포터블 ZIP 다운로드](https://github.com/HooniKims/ssen-player/releases/download/v0.2.2/SsenPlayer-0.2.2-win-x64.zip) | 압축을 모두 풀고 `SsenPlayer.exe`를 실행합니다. `_internal` 폴더도 함께 유지하세요. |

1. **파일 열기**를 누르거나 영상을 창으로 끌어 놓습니다.
2. 오른쪽 **펜·형광펜·지우개**로 설명할 부분을 표시합니다.
3. 한 장면은 **캡처 저장**, 설명 과정은 **수업 녹화**로 저장합니다.
4. **설정 → 저장 폴더 변경**에서 수업 자료를 모아 둘 폴더를 고릅니다.

## 영상 위에 바로 필기

재생 중에도, 일시정지한 장면에도 쓸 수 있습니다. 펜 색상 6가지와 두께 3단계, 형광펜, 획 지우개를 제공합니다. 잘못 그린 획은 **되돌리기**로 취소하고, 필요하면 다시 실행할 수 있습니다. 필기는 영상 좌표를 따라가므로 창 크기나 전체 화면 모드를 바꿔도 같은 위치에 표시됩니다.

화면 위쪽에는 파일 열기·YouTube·재생 목록·설정이 있고, 오른쪽에는 필기·녹화·캡처 도구가 있습니다. 아래에서는 재생 속도, 5초 이동, 음량과 반복을 조절합니다.

## 전체 화면도 수업 상황에 맞게

`F11`을 누르면 **창 모드 → 수업 전체 화면 → 완전 전체 화면**으로 바뀝니다. `Esc`를 누르면 이전 모드로 돌아갑니다.

### 수업 전체 화면

영상은 크게 보여주고, 오른쪽 필기·캡처 도구와 아래 재생 조작은 유지합니다. 학생들에게 장면을 설명하며 표시할 때 사용합니다.

## 장면·설명 과정·원본 구간을 각각 저장

| 원하는 결과 | 사용할 기능 | 저장되는 내용 |
| --- | --- | --- |
| 설명한 장면 한 장 | **캡처 저장** | 현재 영상·표시 중인 자막·필기를 합친 1920×1080 PNG |
| 필기하며 설명한 과정 | **수업 녹화** | 영상과 필기 과정을 담은 720p·20fps MP4. PC 소리·기본 마이크 선택 가능 |
| 원본 영상의 일부 | **구간 설정 → 이 구간을 MP4로 저장** | 선택한 원본 구간의 MP4. 필기는 제외 |

세 종류의 결과는 설정한 저장 폴더에 모입니다. 녹화에 PC 소리를 포함하면 다른 앱의 소리도 함께 녹음됩니다.

## 필요한 부분만 반복해서 보기

영상 아래의 **여기부터 → 여기까지**로 시작과 끝을 지정하거나, **구간 설정**에서 시간을 입력합니다. **반복 재생**을 누르면 지정한 부분을 계속 재생합니다. **구간 목록에 저장**으로 이름을 붙이면 앱을 다시 실행한 뒤에도 해당 영상의 구간을 불러올 수 있습니다.

발음 연습, 실험 과정, 동작 분석처럼 같은 부분을 여러 번 볼 때 사용할 수 있습니다. 아래 예시는 1.0–5.0초 구간을 ‘진자의 한 번 왕복’으로 저장한 화면입니다.

## YouTube도 앱 안에서

상단 **YouTube** 버튼에 영상 링크를 붙여 넣으면 앱 안에서 재생합니다. YouTube 영상에도 필기·반복·수업 녹화를 사용할 수 있으며, 다운로드 가능한 영상은 선택 구간을 MP4로 저장할 수 있습니다.

인터넷 연결이 필요하며 앱 안에서 재생하도록 허용된 영상만 열 수 있습니다. 로그인·연령·지역 제한이나 서비스 변경으로 재생 또는 저장이 제한될 수 있습니다. **광고 차단은 실험 기능이며 모든 광고 제거를 보장하지 않습니다.**

<img src="https://raw.githubusercontent.com/HooniKims/ssen-player/ff517b248fdc13749ae7b74be0a258dcf12b82ca/docs/images/release-0.2.2/youtube.png" alt="YouTube 링크 입력과 광고 차단 안내 화면" width="540">

## 영상 호환성과 기본 재생 기능

- **컨테이너**: MOV, MP4, MKV, AVI, WebM 등의 샘플을 확인했습니다.
- **내장 영상 디코더**: AV1, H.264, HEVC(H.265), VP9, ProRes, MPEG-4, MJPEG 등.
- **음성**: AAC, MP3, AC3, FLAC, Opus, PCM 등.
- **재생 조작**: 0.5–2배속, 5초 이동, 음량·음소거, 재생 목록, 이어보기, 한 편 반복과 구간 반복.
- **자막**: SRT·SMI·VTT 외부 자막, 자막 싱크 조절, 음성·내장 자막 트랙 선택.

MOV는 컨테이너 이름입니다. H.264·HEVC 10bit·ProRes·MJPEG·회전 정보가 포함된 MOV 샘플을 검증했지만, 모든 코덱 조합·손상 파일·DRM 영상의 재생을 보장하지는 않습니다.

## 확인한 범위

`humanize-korean`과 `review-ai-expressions`로 문구를 검토했습니다. 문자 기준 변경률은 3.9%이며 수치·파일명·기능 조건을 유지했습니다. 재생·저장 로직은 변경하지 않았습니다.

설정·YouTube·구간 설정·녹화·업데이트 화면을 100%와 150% 배율로 확인했습니다. 재생 중 필기, 필기 포함 캡처, 전체 화면, 구간 목록 저장, 녹화·구간 파일 저장 검사와 기본 검사 7개도 통과했습니다.

설치 직후 첫 실행에서 Windows `ntdll.dll / 0xc000070a` 오류로 한 번 종료됐습니다. 이후 같은 설치본을 5회 실행해 MOV·AV1 재생과 필기 캡처가 정상임을 확인했지만, 최초 종료 원인은 확인하지 못했습니다. 반복 실행에서 재현되지 않았으며 이 현상을 해결했다고 주장하지 않습니다.

설치본의 YouTube 재생·반복, 영상과 필기 녹화, 구간 MP4 저장, 오디오 모듈 로드 및 정상 제거도 확인했습니다.

프로토타입 사전 릴리즈입니다. 온라인 자동 업데이트 배포 주소와 Windows 코드 서명은 아직 설정되지 않았습니다. YouTube 광고 차단은 실험 기능이며, 실제 전자칠판 입력·장시간 녹화·실장치 마이크 혼합은 현장 검증이 필요합니다. 소프트웨어 디코딩을 기본 사용하므로 고해상도 영상의 성능은 CPU에 영향을 받습니다.
