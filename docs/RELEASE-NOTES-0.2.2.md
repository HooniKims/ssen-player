# 쎈player 0.2.2 · 수업 도구 안내 문구 개선

앱 안의 문구 22종, 23곳을 다듬었습니다. 재생·필기·저장 기능과 내장 코덱은 0.2.1과 같습니다.

- **구간 목록에 저장**: 영상 파일 저장과 구간 위치 저장을 구분했습니다.
- **캡처·녹화·구간 저장 폴더**: 같은 폴더에 저장되는 결과를 설정에서 안내합니다.
- 반복 구간 오류의 A/B 지점을 시작/끝 지점으로 풀었습니다.
- 필기 녹화, YouTube 재생 제한, 광고 차단과 업데이트 안내를 다듬었습니다.

## 다운로드

- **SsenPlayer-Setup-0.2.2.exe**: Windows x64 설치용.
- **SsenPlayer-0.2.2-win-x64.zip**: 압축을 모두 풀고 `SsenPlayer.exe`를 실행합니다. `_internal` 폴더를 함께 유지하세요.

AV1·H.264·HEVC·VP9·ProRes 등의 재생 코덱을 포함하며 별도 코덱 팩이나 Python 설치가 필요 없습니다. 영상 위 필기, 필기 포함 PNG 캡처·MP4 녹화, 구간 반복과 원본 구간 MP4 저장을 지원합니다.

## 화면으로 보는 변경 사항

실제 v0.2.2 앱을 150% 배율로 캡처했습니다. 화면의 저장 경로는 설명용 예시이며, 저장할 폴더는 설정에서 고를 수 있습니다.

### 구간 목록 저장과 MP4 저장

시작과 끝을 정하고 **반복 재생**을 누르면 해당 구간을 반복합니다. **구간 목록에 저장**은 다음에도 같은 구간을 불러오는 기능입니다. 영상 파일이 필요하면 아래의 **이 구간을 MP4로 저장 · 필기 제외**를 누릅니다. 필기까지 저장하려면 수업 녹화를 사용하세요.

### 영상과 필기하는 과정을 함께 녹화

### YouTube 재생 조건과 광고 차단 안내

‘임베드’라는 용어를 **앱 안에서 재생하도록 허용된 영상**으로 풀었습니다. 광고 차단이 모든 광고를 없애지는 못한다는 점과, 재생 오류가 날 때 끄고 다시 시도할 설정도 명시했습니다.

## 확인한 범위

`humanize-korean`과 `review-ai-expressions`로 문구를 검토했습니다. 문자 기준 변경률은 3.9%이며 수치·파일명·기능 조건을 유지했습니다. 재생·저장 로직은 변경하지 않았습니다.

설정·YouTube·구간 설정·녹화·업데이트 화면을 100%와 150% 배율로 확인했습니다. 재생 중 필기, 필기 포함 캡처, 전체 화면, 구간 목록 저장, 녹화·구간 파일 저장 검사와 기본 검사 7개도 통과했습니다.

설치 직후 첫 실행에서 Windows `ntdll.dll / 0xc000070a` 오류로 한 번 종료됐습니다. 이후 같은 설치본을 5회 실행해 MOV·AV1 재생과 필기 캡처가 정상임을 확인했지만, 최초 종료 원인은 확인하지 못했습니다. 반복 실행에서 재현되지 않았으며 이 현상을 해결했다고 주장하지 않습니다.

설치본의 YouTube 재생·반복, 영상과 필기 녹화, 구간 MP4 저장, 오디오 모듈 로드 및 정상 제거도 확인했습니다.

프로토타입 사전 릴리즈입니다. 온라인 자동 업데이트 배포 주소와 Windows 코드 서명은 아직 설정되지 않았습니다. YouTube 광고 차단은 실험 기능이며, 실제 전자칠판 입력·장시간 녹화·실장치 마이크 혼합은 현장 검증이 필요합니다. 소프트웨어 디코딩을 기본 사용하므로 고해상도 영상의 성능은 CPU에 영향을 받습니다.
