# 2026-10-10 재검증 · 0.2.1

기존 6개 영상에 VP9 WebM, AV1 MP4, MPEG-4/MP3 AVI, MJPEG/PCM MOV, H.264/AC3 MKV, H.264/FLAC MKV, 4K 10bit HEVC/AAC, 60fps H.264/AAC를 추가했습니다. 실제 고객 영상이 아닌 재현 가능한 합성 샘플입니다.

## 결과

- **AV1을 포함한 14개 샘플 모두 통과.** 연속 프레임, 음성 디코딩, 일시정지, 중간 탐색, 재개를 확인했습니다. 오디오가 없는 HEVC/ProRes 샘플은 음성 검사를 제외합니다.
- 기본 Qt DLL에서 발견한 AV1 실패를 dav1d 포함 FFmpeg 7.1.5 LGPL 공유 라이브러리로 해결했습니다. Qt가 지원되지 않는 하드웨어 디코더를 고르는 문제를 피하도록 소프트웨어 디코딩을 기본 사용합니다. 전처리 변환 없이 AV1을 직접 재생합니다. 4K HEVC 샘플도 통과했지만 모든 CPU에서 프레임 유지율을 보장하는 성능 검사는 아닙니다.
- MOV 재생 중 마우스 필기, 정지 중 필기, 합성 터치, 필기 픽셀을 포함한 PNG, 되돌리기·다시 실행·전체 지우기, 수업 전체 화면·완전 전체 화면 통과.
- 형광펜·획 지우개·지우기 취소, 음량·음소거·1.5배속·5초 이동, 재생 목록 중복 방지·파일별 필기·이어보기, 외부 자막·싱크·캡처, 구간 반복 해제 통과.
- 빈 화면 캡처 안내, 잘못된 저장 폴더 오류 안내, 설정 대화상자, 최소 1050×690 창 크기 확인.
- 로컬 구간 2초 H.264/AAC MP4 저장, 영상·필기 녹화, 합성 음성 두 트랙 혼합 검사 통과. 실제 마이크를 녹음한 검사는 아님.
- 실제 YouTube 데모 영상 재생·5–7초 반복·필기 캡처·필기 포함 녹화 통과. 광고 요청 3건 차단은 확인했으나 모든 광고 제거를 검증한 것은 아님.

## 디자인

쎈Lite·moa-review의 실제 CSS에서 #f2f0eb / #00754a / #006241, Ghanachocolate, 44px급 캡슐 버튼을 확인했습니다. 네이티브 앱에 같은 글꼴·색·버튼 역할을 적용하고, Phosphor 아이콘과 2열 필기 도구로 정돈했습니다. 1280×820와 1050×690 화면 및 전체 화면을 확인했습니다.

화면 예시: [player-0.2.1.png](images/player-0.2.1.png). 원시 테스트 로그·영상은 artifacts/qa에 로컬 보관합니다. 실제 전자칠판 입력, 장시간 녹화, 실장치 오디오 동기 및 모든 코덱 지원은 검증하지 않았습니다.

기존 20/40px 비트맵 아이콘 대신 SVG 엔진을 사용합니다. 100/125/150/200% 창 배율과 100–400% 아이콘 요청에서 요청한 물리 픽셀 수·DPR을 확인합니다. 선택/비선택 색상 모두 같은 벡터 경로를 사용합니다.
