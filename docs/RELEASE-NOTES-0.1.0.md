# 쎈player 0.1.0 · 수업용 첫 테스트 버전

- MOV(H.264/HEVC/ProRes), MP4, MKV 샘플 재생 검증. FFmpeg 코덱 포함.
- 재생 중 / 정지 중 영상 위 필기, 형광펜, 지우개, 되돌리기.
- 영상 + 자막 + 필기를 PNG로 캡처하여 지정 폴더에 저장.
- 우측 수업 도구가 있는 전체 화면과 완전 전체 화면.
- 배속, A–B 반복, 재생 목록, 이어보기, SRT/SMI/VTT 자막.
- 한국어 Windows x64 설치형 EXE 및 무설치 ZIP.

설치형은 Setup EXE를 실행하세요. ZIP은 전체 압축 해제 후 SsenPlayer/SsenPlayer.exe를 실행하세요.

첫 프로토타입입니다. 실물 전자칠판과 HDR 색 정확도는 미검증이며, 자동 업데이트 배포 주소는 아직 연결되지 않았습니다. Windows 코드 서명은 포함되지 않습니다.
