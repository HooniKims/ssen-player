# 1.2.0 검증 · 2026-10-14

## 소스 검사

- Python 단위 시험 28개 통과. 여러 링크 입력의 순서·중복·잘못된 링크, 재생을 끊지 않는 추가, 순서 변경·삭제, 마지막 항목 정지, 한 편/구간 반복 우선, 로컬/YouTube 전환과 이전 영상의 늦은 상태 응답을 검사했다.
- 공통 인증 키트 Node 시험 17개와 브라우저 암호 벡터 61개 통과.
- `scripts/playlist_smoke.py`: 실제 YouTube 영상 두 편으로 입력 대화상자, 자동 다음 재생, YouTube → 로컬, 로컬 → YouTube 전환 통과. 격리된 설정과 인증 없는 재생 권한을 사용했다. 영상 끝 1초 전으로 탐색한 뒤 실제 종료 이벤트로 전환했다.
- `scripts/smoke_test.py`: 실제 MOV 재생, 재생·정지 중 필기와 캡처, 합성 터치, 전체 화면 전환 통과. 프로세스 종료 코드 0.
- 링크 추가 대화상자와 재생 목록 화면 캡처를 확인했다.

## 패키징 앱 검사

- `dist/SsenPlayer/SsenPlayer.exe --auth-test-output`을 MOV와 AV1 샘플 각각으로 실행해 종료 코드 0 확인. 격리된 임시 저장소와 서명 없는 가짜 인증 서버를 사용했다.
- 두 샘플 모두 실제 영상 프레임을 디코딩했다. 인증 전 재생 허용, 필기·캡처·내보내기·설정 저장 차단, 브라우저 엔진의 서명 거부, 기본 앱 한글 안내, 전체 화면 안내 숨김 검사 통과.
- 배포 아카이브 안의 버전 1.2.0과 재생 목록 구현 존재, 소스 시험용 권한 모듈 제외 확인.
- 번들 PySide6 재생 DLL 5개의 SHA-256이 고정 vendor 원본과 일치함을 확인했다.
- `scripts/verify_legal.py`: 약관 일치, EXE 저작권, 비공개 문서 제외, 기존 사용자 출력 265개의 표식 미포함 검사 통과.

## 검증 범위

실제 이메일 인증·학교망·다른 앱 계정 공유와 서버 scope 등록 검증은 이번에도 수행하지 않았다. 기존 1.1.0 사용자 설치가 있어 이 PC의 설치·제거 회귀시험은 실행하지 않았다. 실제 전자칠판 입력, 다른 PC, HDR 원본 검증은 포함하지 않는다. YouTube 검사는 당시 접근 가능한 두 공개 영상에 대한 결과다.
