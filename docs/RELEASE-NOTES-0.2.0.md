# 쎈player 0.2.0 · 수업 구간과 녹화

- YouTube 링크를 앱 안에서 임베드 재생하고 위에 필기·캡처합니다.
- **여기부터 → 여기까지**로 구간을 반복합니다. 구간 설정에서 시간을 조절하고 이름을 붙여 저장·다시 재생합니다.
- 로컬·YouTube 영상의 선택 구간을 MP4로 저장합니다. 원본 구간 저장에는 필기가 제외됩니다.
- **수업 녹화**로 영상과 움직이는 필기를 함께 MP4에 담습니다. PC 소리와 선택한 마이크를 포함할 수 있습니다.
- MOV 재생, 필기 포함 PNG 캡처, 두 가지 전체 화면을 유지합니다.

설치: `SsenPlayer-Setup-0.2.0.exe`. 무설치판은 ZIP 전체를 풀고 실행하세요.

YouTube 광고 차단·건너뛰기는 실험 기능이며 모든 광고 제거를 보장하지 않습니다. 제한된 영상이나 서비스 변경으로 재생·구간 저장이 실패할 수 있습니다. 브라우저와 녹화 엔진 추가로 설치 용량이 증가했습니다.

전자칠판 실물·장시간 녹화·실제 마이크 혼합은 현장 검증이 필요합니다. 자동 업데이트 배포 주소는 아직 연결되지 않았으며 이 비공개 릴리즈에서 설치 파일을 받습니다. Windows 코드 서명은 없습니다.
