# 쎈Player 1.3.0

- 로고 옆 버전·빨간점과 우측 하단 민트색 알림으로 새 업데이트를 확인합니다. 상세창에서 실제 변경 내용과 파일 크기를 보고 자동 확인·버전 건너뛰기를 설정할 수 있습니다.
- 설치형 업데이트는 다운로드·검증 후 저장 여부를 확인하고 직접 재시작을 선택합니다. 포터블은 공식 페이지에서 새 ZIP을 받아 수동으로 교체합니다.
- 상단 자막 버튼과 드래그 앤 드롭으로 SRT·SMI/SAMI·VTT 자막을 적용합니다. 현재 재생 위치와 일시 정지를 유지하며 영상과 자막을 함께 끌어 놓을 수도 있습니다.

자동 업데이트 확인은 시작 15초 뒤, 이후 4시간마다입니다. ‘나중에’와 X는 카드만 닫고 빨간점을 유지합니다. ‘이 버전 건너뛰기’는 재실행 후에도 유지되며 다음 새 버전은 다시 알립니다. 자동 확인을 꺼도 수동 확인과 업데이트는 사용할 수 있습니다.

1.2.1의 단일 실행 동작도 포함합니다. 이미 켜져 있는 플레이어에 새 영상을 열면 기존 재생 목록 끝에 추가하고 현재 재생은 유지합니다.

설치형은 아래 Setup 파일을 사용하세요. 포터블 ZIP은 압축을 풀고 폴더 전체를 유지해야 합니다. 설치 전 필요한 필기는 캡처로 저장해 주세요. 기존 사용자 설치와 실제 계정은 배포 검증 중 변경하지 않았습니다.

업데이트 상태·다운로드·재시작 확인 UI는 모의 릴리스와 모의 다운로드로 검사했습니다. 실제 영상 재생·자막 드롭과 배포 패키지 검사는 별도로 수행했습니다. 자세한 검증 범위는 저장소의 `docs/VALIDATION-1.3.0.md`에 기록합니다.
