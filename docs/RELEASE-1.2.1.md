# 쎈Player 1.2.1 · 중복 실행 수정

쎈플레이어를 기본 동영상 앱으로 사용하면서 다른 파일을 열어도 플레이어 창이 여러 개 생기지 않습니다.

- 앱이 닫혀 있으면 창 하나를 열고 선택한 영상을 재생합니다.
- 앱이 열려 있으면 새 파일을 기존 재생 목록 끝에 추가합니다. 현재 재생 중이거나 일시 정지한 영상은 그대로 유지됩니다.
- 아직 재생 중인 영상이 없는 빈 창에서는 첫 파일을 바로 재생합니다.
- 여러 파일을 연달아 열거나 앱이 시작되는 중에 파일을 열어도 기존 창으로 전달합니다.
- 목록에 이미 있는 파일은 중복으로 추가하지 않습니다. 최소화된 창은 복원됩니다.

처음 업데이트할 때에는 기존 버전의 창을 모두 닫은 뒤 1.2.1을 실행해 주세요.

## 다운로드

- `SsenPlayer-Setup-1.2.1.exe`: Windows x64 설치 파일
- `SsenPlayer-1.2.1-win-x64.zip`: 압축을 풀고 `SsenPlayer/SsenPlayer.exe` 실행
- `update.json`: 기존 앱의 자동 업데이트용 정보
