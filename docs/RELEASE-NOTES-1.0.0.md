# 쎈player 1.0.0 · 전자칠판 수업용 영상 플레이어

**영상을 보면서 바로 필기하고, 설명한 장면을 수업 자료로 저장하세요.**

쎈player는 Windows PC와 전자칠판에서 쓰는 수업용 영상 플레이어입니다. 재생 중이든 멈춘 장면이든 펜과 형광펜으로 표시하고, 필요한 장면은 필기와 함께 캡처하거나 녹화합니다. 같은 부분을 여러 번 설명할 때는 구간 반복을 씁니다.

로컬 영상은 광고 없이 재생하며 AV1·H.264·HEVC 등의 코덱이 들어 있어 코덱 팩이나 Python을 따로 설치하지 않아도 됩니다. YouTube 링크도 앱 안에서 열 수 있습니다.

1.0.0에서는 앱 안에서 YouTube를 검색하고, 쎈player를 기본 동영상 앱으로 선택할 수 있습니다. 자체 이용약관과 저작권 표시도 추가했습니다.

<img src="https://raw.githubusercontent.com/HooniKims/ssen-player/v0.2.3/docs/images/intro-0.2.3/01-video-ink.png" alt="진자 예시 영상에 빨간 펜으로 표시한 쎈player 화면" width="1000">

*실제 앱 화면입니다(0.2.3에서 촬영, 기존 재생·필기 화면 예시). 진자 영상은 소개용으로 직접 만든 예시이고, 빨간 원과 화살표는 플레이어의 펜으로 그렸습니다. 예시 영상은 설치 파일에 들어 있지 않습니다.*

## 1.0.0에서 달라진 점

- 처음 실행할 때 기본 앱 설정을 안내합니다. 설정의 **기본 동영상 앱으로 설정**에서도 Windows 선택 화면을 열 수 있습니다. 다른 플레이어는 삭제하지 않습니다.
- 설치 시 이용약관에 동의해야 진행할 수 있습니다. 설정과 업데이트 창 하단의 **이용약관 보기**에서 전문을 펼치거나 닫을 수 있습니다.

### 기존 기능

업데이트 방식을 쎈Pick 등 다른 쎈 앱과 같게 맞췄습니다. 앱은 GitHub 릴리스에서 새 버전을 확인하고, 내려받은 설치 파일의 크기와 SHA-256 해시가 맞을 때만 설치합니다.

## 0.2.3에서 추가된 기능

### 5초 후 재생으로 녹화 시작 맞추기

쎈컷 같은 화면 녹화 프로그램으로 영상을 녹화할 때, 녹화 시작과 영상 재생을 같은 순간에 맞춥니다.

1. 영상이나 YouTube 링크를 엽니다.
2. 아래 재생 버튼 오른쪽의 **타이머 버튼**을 누릅니다. 영상이 멈추고 화면 가운데에 **5 → 4 → 3 → 2 → 1**이 1초 간격으로 표시됩니다.
3. 숫자가 바뀌는 동안 녹화 프로그램의 시작 버튼 위에 마우스를 올려 둡니다.
4. **1이 사라지는 순간이 0입니다.** 이때 재생이 시작되니, 같은 순간에 녹화 버튼을 누르세요.

숫자는 재생 직전에 사라지므로 0에 녹화를 시작하면 녹화 영상에 숫자가 남지 않습니다. 카운트다운 중에 타이머 버튼을 다시 누르면 취소됩니다. 재생 버튼을 누르면 바로 재생됩니다. 영상은 멈춘 위치부터 다시 재생되니, 처음부터 녹화하려면 숫자가 바뀌는 동안 탐색 막대 맨 앞을 누르세요.

<img src="https://raw.githubusercontent.com/HooniKims/ssen-player/v0.2.3/docs/images/intro-0.2.3/03-countdown.png" alt="영상 가운데에 숫자 3이 표시되고 타이머 버튼이 켜진 카운트다운 화면" width="1000">

### 새 버전 알림

앱을 켜고 3초쯤 지나면 GitHub 릴리스에서 새 버전을 확인합니다. 새 버전이 있으면 **지금 업데이트**와 **다음에** 중 하나를 고릅니다. **다음에**를 누르면 다음에 앱을 켤 때 다시 알려 줍니다.

- 수업 전체 화면을 쓰고 있거나 녹화 중이면 창을 띄우지 않고 아래 상태 줄에만 알립니다.
- 인터넷이 없거나 확인에 실패하면 아무것도 표시하지 않습니다.
- 설치 파일은 크기와 SHA-256 해시를 확인한 뒤에 설치합니다. 내려받다가 손상되거나 바뀐 파일은 설치하지 않습니다.
- **설정 → 업데이트 확인**을 누르면 언제든 직접 확인합니다.

<img src="https://raw.githubusercontent.com/HooniKims/ssen-player/v0.2.3/docs/images/intro-0.2.3/07-update-notice.png" alt="새 버전 0.2.4가 나왔다는 알림과 지금 업데이트, 다음에 버튼" width="460">

*0.2.3을 쓰는 PC에 0.2.4 알림이 뜬 모습입니다.*

### 전자칠판에서 더 편하게

- 완전 전체 화면에서 YouTube를 볼 때도 화면을 터치하면 **수업 도구 보기** 버튼이 나타납니다. 이전에는 로컬 영상에서만 나타나서, 키보드가 없는 전자칠판에서는 YouTube 완전 전체 화면을 빠져나오기 어려웠습니다.
- 탐색 막대와 음량 막대를 누르면 그 위치로 바로 이동합니다. 이전에는 누른 곳으로 가지 않고 원래 위치로 되돌아갔습니다.
- 색이나 펜 굵기를 고르면 펜으로 바뀝니다. 선택 도구나 지우개 상태에서 색만 바꾸고 영상을 누르면 필기 대신 재생이나 정지가 되던 문제를 고쳤습니다.
- 지우개로 빈 곳을 눌러도 되돌리기 기록이 쌓이지 않습니다. 되돌리기를 눌렀는데 아무 변화가 없는 일이 줄었습니다.
- YouTube에서 바꾼 재생 속도가 로컬 영상으로 돌아왔을 때도 그대로 적용됩니다.
- 수업 녹화를 할 때 컴퓨터 부담이 줄었습니다. 녹화 결과는 이전과 같은 720p·20fps MP4입니다.

## 사용 방법

1. **파일 열기**를 누르거나 영상을 창으로 끌어 놓습니다. 여러 파일을 열면 재생 목록에 들어갑니다.
2. 오른쪽 **펜·형광펜·지우개**로 설명할 부분을 표시합니다.
3. 한 장면은 **캡처 저장**, 설명하는 과정은 **수업 녹화**로 저장합니다.
4. **설정 → 저장 폴더 변경**에서 수업 자료를 모아 둘 폴더를 고릅니다.

## 영상 위에 바로 필기

재생 중에도 멈춘 장면에도 씁니다. 펜 색 6가지와 굵기 3단계, 형광펜, 획 지우개, 문지른 부분만 지우는 부분 지우개가 있습니다. 잘못 그린 획은 **되돌리기**로 취소하고 **다시 실행**으로 되살립니다. 필기는 영상 위치를 기준으로 저장되므로 창 크기를 바꾸거나 전체 화면으로 바꿔도 같은 자리에 남습니다.

## 수업 상황에 맞는 세 가지 화면

`F11`을 누를 때마다 **창 모드 → 수업 전체 화면 → 완전 전체 화면** 순서로 바뀌고, `Esc`를 누르면 이전 화면으로 돌아갑니다.

- **수업 전체 화면**: 영상을 크게 보여 주면서 오른쪽 필기·캡처 도구와 아래 재생 조작을 그대로 둡니다. 장면을 짚어 가며 설명할 때 씁니다.
- **완전 전체 화면**: 도구를 모두 숨기고 영상과 이미 쓴 필기만 보여 줍니다. 화면을 터치하거나 마우스를 움직이면 **수업 도구 보기** 버튼이 잠시 나타납니다.

## 장면·설명 과정·원본 구간을 따로 저장

| 남기고 싶은 것 | 사용할 기능 | 저장되는 내용 |
| --- | --- | --- |
| 설명한 장면 한 장 | **캡처 저장** | 영상·표시 중인 자막·필기를 합친 1920×1080 PNG |
| 필기하며 설명한 과정 | **수업 녹화** | 영상과 필기 과정을 담은 720p·20fps MP4. PC 소리와 기본 마이크를 고를 수 있음 |
| 원본 영상의 일부 | **구간 설정 → 이 구간을 MP4로 저장** | 고른 구간의 원본 MP4. 필기는 들어가지 않음 |

세 가지 모두 설정한 저장 폴더에 모입니다. 녹화에 PC 소리를 넣으면 다른 앱의 소리도 함께 녹음됩니다.

## YouTube도 앱 안에서

위쪽 **YouTube** 버튼에서 검색어로 영상을 찾고 선택하면 앱 안에서 재생합니다. 영상 링크를 붙여 넣어도 됩니다. 필기, 반복, 수업 녹화, 5초 후 재생도 YouTube 영상에 그대로 쓰고, 내려받기가 허용된 영상은 고른 구간을 MP4로 저장합니다.

인터넷 연결이 필요하며, 앱 안 재생이 허용된 영상만 열립니다. 로그인·연령·지역 제한이나 YouTube 쪽 변경 때문에 재생이나 저장이 안 될 수 있습니다. **광고 차단은 실험 기능이라 모든 광고를 막지는 못합니다.**

## 지원 형식과 기본 기능

- **파일 형식**: MOV, MP4, MKV, AVI, WebM 등
- **영상 코덱**: AV1, H.264, HEVC(H.265), VP9, ProRes, MPEG-4, MJPEG 등
- **음성 코덱**: AAC, MP3, AC3, FLAC, Opus, PCM 등
- **재생 조작**: 0.5–2배속, 5초 이동, 음량·음소거, 재생 목록, 이어 보기, 한 편 반복, 구간 반복, 5초 후 재생
- **자막**: SRT·SMI·VTT 외부 자막, 자막 싱크 조절, 음성·내장 자막 트랙 선택

모든 코덱 조합이나 손상된 파일, DRM 영상까지 재생된다고 보장하지는 않습니다.

## 확인한 내용과 남은 한계

단위 테스트 16개, 영상 코덱·재생·필기·녹화·구간 저장·YouTube 회귀 검증을 통과했습니다. 실제 배포 EXE에서 MOV 재생, 필기를 포함한 캡처, 약관 읽기·펼치기·닫기, YouTube 반복·녹화·구간 MP4 저장을 확인했습니다. 설치본에 들어 있는 약관 원문과 EXE의 저작권 속성도 확인했습니다.

기존 사용자 설치를 덮어쓰지 않기 위해 설치본을 별도 폴더에 풀어 검증했습니다. 이번 작업에서 실제 설치·제거 및 설치 약관 화면 캡처는 진행하지 못했습니다. Windows 화면 자동화 연결이 제공되지 않아 앱 안 설정·업데이트 화면을 캡처했습니다.

- 실제 전자칠판의 펜·손가락 입력, 장시간 녹화, 마이크와 스피커 동시 녹음은 현장에서 더 확인해야 합니다. 터치 동작은 실제 전자칠판이 아닌 PC의 모의 터치 입력으로 확인했습니다.
