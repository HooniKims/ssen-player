# 0.2.0 검증

개발 PC Windows 11 / Python 3.12 / Qt 6.10.2에서 확인했습니다.

- 단위 테스트 7개 통과: 필기, 자막, 업데이트 서명/해시, YouTube URL, 광고 필터.
- MOV 재생·필기·캡처 기존 통합 검사 통과.
- 로컬 영상의 A–B 반복 및 이름을 붙인 구간 저장·재호출 통과.
- 영상 재생 및 일시정지 중 필기를 합성한 약 3초 MP4 녹화 통과.
- 합성 오디오 두 트랙을 녹화에 혼합하여 AAC 저장 확인. 실제 마이크는 녹음하지 않음.
- 로컬 2–4초 구간 MP4 저장, 영상·음성 확인.
- 실제 YouTube 공개 데모 M7lc1UVf-VE 임베드 재생, 5–7초 반복, 필기 PNG 및 필기 포함 무음 녹화 통과.
- 같은 YouTube의 2–4초 구간 다운로드·MP4 저장 통과: 2.007초 H.264/AAC.
- 해당 재생에서 필터가 광고 요청 3건을 차단했음. 모든 광고가 차단된다는 검증은 아님.
- 패키징한 EXE에서도 YouTube 재생·반복·필기 PNG·4.15초 H.264 녹화·2.007초 H.264/AAC 구간 저장 통과.
- 최종 설치형 EXE를 격리 폴더에 설치하여 MOV 디코딩·필기 캡처, YouTube 반복·녹화·구간 저장, 오디오 모듈 로딩을 확인한 뒤 제거까지 통과. 해당 실행의 창 준비 시간은 2.143초로, 일반적인 성능 보장은 아님.
- 설치 파일 188,447,859바이트(약 180MiB), 무설치 ZIP 270,885,343바이트(약 258MiB). ZIP 전체 무결성 검사 통과.

실제 전자칠판의 펜·손바닥 거부, 장시간 녹화 안정성, 실장치 오디오 동기, 저사양 PC 성능은 미검증입니다. 테스트 출력은 artifacts/qa에 로컬 보관하며 저장소에는 올리지 않습니다.
