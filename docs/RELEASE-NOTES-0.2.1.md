# 쎈player 0.2.1 · AV1 내장과 수업 도구 개선

Windows 전자칠판 수업용 영상 플레이어입니다. 영상 위에 필기하고, 영상과 필기를 캡처하거나 MP4로 녹화할 수 있습니다. **프로토타입 사전 릴리즈**이며 누구나 아래 설치 파일을 내려받을 수 있습니다.

## 다운로드

- **SsenPlayer-Setup-0.2.1.exe**: 일반 설치용. Windows x64에서 실행합니다.
- **SsenPlayer-0.2.1-win-x64.zip**: 설치 없이 사용하는 포터블 버전. 전체 압축을 풀고 `SsenPlayer.exe`를 실행합니다. `_internal` 폴더를 함께 유지하세요.
- Python이나 별도 코덱 팩을 설치할 필요가 없습니다.

## 이번 버전 변경 사항

- 쎈Lite·moa-review의 가나초콜릿 글꼴, 초록색 강조, 캡슐형 버튼을 반영했습니다.
- 선 아이콘과 2열 필기 도구, 되돌리기·지우기 아이콘 바를 적용했습니다.
- 캡처·반복·녹화 버튼은 쉽게 누를 수 있는 크기를 유지하고 보조 버튼을 정돈했습니다.
- 영상·음성 디코딩, 정지·탐색·재개, 필기·캡처·반복·녹화·YouTube를 다시 검증했습니다.

- 저해상도 비트맵 아이콘을 화면 배율에 맞춰 그리는 SVG로 교체했습니다.
- AV1 소프트웨어 디코더(dav1d)를 포함한 FFmpeg 라이브러리를 함께 제공합니다. 별도 코덱 설치나 사전 변환 없이 직접 재생합니다.

## 포함된 재생 코덱과 확인한 형식

영상: **AV1, H.264, HEVC(H.265), VP9, ProRes, MPEG-4, MJPEG** 등.
음성: **AAC, MP3, AC3, FLAC, Opus, PCM** 등.

MOV(H.264·HEVC 10bit·ProRes·MJPEG·회전 정보), MP4(AV1 포함), MKV, AVI, WebM의 합성 샘플 14개에서 연속 재생, 음성 디코딩, 정지, 탐색, 재개를 확인했습니다. 4K HEVC와 60fps H.264 샘플도 포함됩니다. 확장자는 컨테이너이므로 모든 파일의 재생을 보장하는 의미는 아닙니다.

## 수업에서 사용하기

1. 파일을 열거나 영상을 끌어 놓습니다. YouTube는 상단 버튼에 링크를 붙여 넣습니다.
2. 오른쪽에서 펜·형광펜·지우개를 선택합니다. 재생 중과 일시정지 중 모두 필기할 수 있습니다.
3. **캡처 저장**으로 영상+자막+필기를 PNG로 저장합니다. **설정 → 저장 폴더 변경**에서 위치를 지정합니다.
4. **수업 녹화**로 영상과 움직이는 필기를 720p/20fps MP4로 저장합니다. PC 소리와 선택한 마이크를 사용할 수 있습니다.
5. **여기부터 → 여기까지** 또는 **구간 설정**으로 반복 구간을 지정합니다. 이름을 붙여 기억하거나 원본 구간만 MP4로 저장할 수 있습니다. 구간 저장에는 필기가 포함되지 않으며, 필기까지 보관하려면 수업 녹화를 사용하세요.
6. `F11`로 창 → 수업 전체 화면(도구 표시) → 완전 전체 화면을 전환합니다. `Esc`로 돌아옵니다.

## 검증 및 남은 범위

필기·캡처·되돌리기·터치 합성 입력·자막·재생 목록·반복·로컬 구간 저장·영상+필기 녹화·YouTube 반복을 재검증했습니다. 100/125/150/200% 창 배율과 100–400% 아이콘 픽셀 크기를 확인했습니다.

호환성을 위해 소프트웨어 디코딩을 기본 사용하므로 고해상도 재생 성능은 CPU에 영향을 받습니다. 모든 코덱·DRM 영상 지원을 보장하지 않습니다.

YouTube 광고 차단은 실험 기능입니다. 자동 업데이트 배포 주소, 전자칠판 실물, 장시간 녹화와 실제 마이크 혼합 검증은 아직 남아 있습니다.

YouTube의 임베드 금지·로그인·지역 제한 등에 따라 재생이나 구간 저장이 제한될 수 있습니다. Windows 코드 서명은 아직 적용되지 않았습니다. 온라인 자동 업데이트는 배포 주소와 서명 공개키를 연결한 뒤 사용할 수 있습니다.
