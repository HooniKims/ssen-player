# 쎈player 1.0.1 · 기존 1.0.0 업데이트 지원

미리 설치한 1.0.0에서도 새 배포본을 업데이트로 인식하도록 버전을 1.0.1로 올렸습니다. 기능은 직전 정식 배포본 1.0.0과 같습니다.

- 앱 실행 후 새 버전 알림에서 **지금 업데이트**를 누르거나, **설정 → 업데이트 확인**에서 진행하세요.
- YouTube 앱 안 검색, 기본 동영상 앱 설정, 필기·캡처·녹화·구간 반복이 포함되어 있습니다.
- 설정과 업데이트 창에서 저작권 옆 **이용약관 보기**를 누르면 전문이 펼쳐집니다.
- 자체 이용약관은 1.0.0부터 적용되며, 함께 제공하는 오픈소스는 각자의 라이선스를 따릅니다.
