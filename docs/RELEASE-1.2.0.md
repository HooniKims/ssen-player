# 쎈Player 1.2.0 · YouTube 재생 목록

여러 YouTube 링크를 미리 추가하고 원하는 순서대로 이어서 볼 수 있습니다.

## 사용 방법

1. **재생 목록 → YouTube 링크 추가**를 누릅니다.
2. 링크를 한 줄에 하나씩 붙여 넣습니다. 공백으로 구분해도 됩니다.
3. **목록에 추가**를 누릅니다. 현재 재생은 계속되며, 바로 시작하려면 **추가한 첫 영상부터 바로 재생**을 선택합니다.
4. 목록 항목을 두 번 누르면 그 영상부터 재생합니다. **위로 / 아래로 / 삭제**로 목록을 정리할 수 있습니다.

## 변경 사항

- 영상이 끝나면 다음 항목을 자동 재생하고, 마지막 영상이 끝나면 멈춥니다.
- 로컬 파일과 YouTube 영상을 같은 목록에서 이어서 재생합니다. 기존 이전·다음 버튼도 함께 사용할 수 있습니다.
- 검색 화면에서 연 YouTube 영상도 목록에 추가합니다. 재생한 영상은 제목으로 표시합니다.
- 중복 영상은 한 번만 추가합니다. 잘못된 링크가 있으면 위치를 안내하며 전체 입력을 수정한 뒤 다시 추가할 수 있습니다.
- 한 편 반복과 구간 반복이 켜져 있으면 반복 재생이 우선합니다.
- 영상 전환 후 늦게 도착한 이전 영상의 상태가 목록 항목을 건너뛰지 않도록 처리했습니다.

재생 목록은 앱을 닫으면 비워집니다. 재생 중인 항목은 다른 영상을 연 뒤 삭제할 수 있습니다. YouTube 자체 재생목록 주소의 자동 가져오기는 지원하지 않으므로 개별 영상 링크를 붙여 넣어 주세요.

## 다운로드

- `SsenPlayer-Setup-1.2.0.exe`: Windows x64 설치 파일
- `SsenPlayer-1.2.0-win-x64.zip`: 압축을 풀고 `SsenPlayer/SsenPlayer.exe` 실행
- `update.json`: 기존 앱의 자동 업데이트용 정보
