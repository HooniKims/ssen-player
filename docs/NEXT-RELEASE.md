# 다음 배포에 포함할 변경

1.0.0에 포함한 변경입니다. 이용약관과 저작권 표시를 함께 반영했습니다.

## 기본 동영상 앱

- 설치할 때 MOV·MP4·MKV 등 14개 동영상 형식의 연결 프로그램 후보로 등록합니다.
- 영상을 열지 않고 처음 실행하면 기본 앱 설정 안내가 한 번 표시됩니다. **나중에**를 선택해도 설정의 **기본 동영상 앱으로 설정**에서 다시 열 수 있습니다.
- **기본 앱 설정 열기**는 Windows 설정의 쎈player 페이지로 연결됩니다. 사용자가 해당 파일 형식의 기본 앱을 선택해야 더블클릭으로 쎈player가 열립니다.
- 포터블 EXE에서도 설정 버튼을 누르면 해당 EXE를 후보로 등록합니다. 등록한 폴더를 옮겼다면 새 위치에서 다시 설정해야 합니다.
- 다른 플레이어를 삭제하거나 기존 기본 앱을 강제로 바꾸지 않습니다.

## 앱 안에서 YouTube 검색

- YouTube 버튼을 누르면 앱 안에 검색 화면이 열립니다.
- 검색어를 입력하거나 영상 주소를 붙여 넣을 수 있습니다.
- 검색 결과에서 영상을 선택하면 기존 수업 재생 화면으로 이동합니다. 필기·캡처·구간 반복 기능을 이어서 사용합니다.
- 검색 화면은 YouTube 웹사이트를 표시하므로 인터넷 연결이 필요합니다. 선택한 영상은 기존과 같이 앱 내 재생을 허용한 경우에 재생됩니다.

## 확인한 내용

- 단위 테스트 14개 통과. 기본 앱 후보 등록이 UserChoice나 확장자의 기존 기본값을 덮어쓰지 않는지, 공백·한글 경로의 실행 명령을 확인했습니다.
- 파일 연결 등록 항목을 포함한 별도의 최소 설치 스크립트가 Inno Setup 컴파일을 통과했습니다. 설치하거나 PC 기본 앱을 변경하지 않았습니다.
- 실제 YouTube에서 `mathematics`를 검색하고 검색 결과를 클릭했을 때 선택한 영상 ID로 창이 종료되는 것을 확인했습니다.
- 전체 설치본의 파일 더블클릭 연결과 최종 배포 검증은 이용약관 추가 후 진행합니다.


## 1.1.0 로컬 작업 중 · 게시하지 않음

- 디자인 통일(쎈 시리즈 공통 디자인 v1.0): 글꼴·버튼·패널·헤더·로고·앱 아이콘.
- 본문 Cafe24 PRO Slim Air, 제목 Max, 버튼 학교안심 자연을 공식 배포처에서 받아 오프라인 내장. 가이드의 Bold 대신 공식 v2.0의 굵은 Max 사용. 라이선스는 assets/licenses에 포함.
- 재생·필기 색상과 파일 처리 방식은 유지. 좁은 화면의 재생 도구는 기존 순서대로 줄바꿈.
- ssencut-authbridge-ref.zip을 참고해 쎈 시리즈 공통 인증 연결. 이메일 인증, 센스쿨 교육용 계정, 무료 체험, 통합 이용권, 등록 PC 관리 화면을 포함.
- 재생은 인증 없이 가능. 필기·캡처·녹화·구간 저장·설정 변경은 인증 후 사용.
- 설치 ID·업데이트 방식 유지. 기본 앱 안내의 깨진 문구도 복원.
- 공통 저장소 DPAPI 상호 호환/CAS, 원본 키트 17개, Python 단위 21개, 실제 Qt 인증 창과 UI/직접 호출 차단, MOV/필기/캡처/녹화/구간 저장 회귀시험 확인.
- 실제 메일 인증과 서버의 player scope 지원은 아직 확인하지 않음. 이번 변경은 게시하지 않음.

- 기본 앱 설정 안내의 물음표 오류를 한글로 복원하고 두 버튼 표시를 실제 Qt 화면에서 확인.
- 참고 ZIP의 공개 시험 벡터를 Chromium에서 실행한 서명/키 목록/범위 검사 61개 통과. 운영 서버 /keys 조회 HTTP 200 (이메일·PC 등록 요청은 보내지 않음).

- 최종 로컬 설치 파일: artifacts/SsenPlayer-Setup-1.1.0.exe. 설치 아카이브 전체 무결성 통과, 내부 EXE가 시험한 EXE와 동일한 해시임을 확인.
- 실제 패키지에서 MOV·AV1의 인증 없는 재생, 인증 창, 기본 앱 안내 한글/두 버튼, UI·실행부 잠금, 완전 전체 화면 안내줄 숨김 확인. artifacts/qa/1.1.0-validation.json에 기록.
- 캡처: artifacts/qa/auth-1.1.0-packaged/{protected-player,license-window,default-app-korean}.png.
- 아직 실제 PC에 설치하거나 게시하지 않았음. 게시 전 서버 player scope 등록, 다른 쎈 앱의 기존 계정 공유, 학교망에서 이메일 인증/PC 등록을 확인해야 함.
