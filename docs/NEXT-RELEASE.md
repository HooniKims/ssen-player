# 다음 배포에 포함할 변경

1.0.0에 포함한 변경입니다. 이용약관과 저작권 표시를 함께 반영했습니다.

## 기본 동영상 앱

- 설치할 때 MOV·MP4·MKV 등 14개 동영상 형식의 연결 프로그램 후보로 등록합니다.
- 영상을 열지 않고 처음 실행하면 기본 앱 설정 안내가 한 번 표시됩니다. **나중에**를 선택해도 설정의 **기본 동영상 앱으로 설정**에서 다시 열 수 있습니다.
- **기본 앱 설정 열기**는 Windows 설정의 쎈player 페이지로 연결됩니다. 사용자가 해당 파일 형식의 기본 앱을 선택해야 더블클릭으로 쎈player가 열립니다.
- 포터블 EXE에서도 설정 버튼을 누르면 해당 EXE를 후보로 등록합니다. 등록한 폴더를 옮겼다면 새 위치에서 다시 설정해야 합니다.
- 다른 플레이어를 삭제하거나 기존 기본 앱을 강제로 바꾸지 않습니다.

## 앱 안에서 YouTube 검색

- YouTube 버튼을 누르면 앱 안에 검색 화면이 열립니다.
- 검색어를 입력하거나 영상 주소를 붙여 넣을 수 있습니다.
- 검색 결과에서 영상을 선택하면 기존 수업 재생 화면으로 이동합니다. 필기·캡처·구간 반복 기능을 이어서 사용합니다.
- 검색 화면은 YouTube 웹사이트를 표시하므로 인터넷 연결이 필요합니다. 선택한 영상은 기존과 같이 앱 내 재생을 허용한 경우에 재생됩니다.

## 확인한 내용

- 단위 테스트 14개 통과. 기본 앱 후보 등록이 UserChoice나 확장자의 기존 기본값을 덮어쓰지 않는지, 공백·한글 경로의 실행 명령을 확인했습니다.
- 파일 연결 등록 항목을 포함한 별도의 최소 설치 스크립트가 Inno Setup 컴파일을 통과했습니다. 설치하거나 PC 기본 앱을 변경하지 않았습니다.
- 실제 YouTube에서 `mathematics`를 검색하고 검색 결과를 클릭했을 때 선택한 영상 ID로 창이 종료되는 것을 확인했습니다.
- 전체 설치본의 파일 더블클릭 연결과 최종 배포 검증은 이용약관 추가 후 진행합니다.
